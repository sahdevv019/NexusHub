# 🚀 NexusHub — My Personal Project Hub

NexusHub is a modern, responsive platform I built to showcase and manage my development projects, including web applications, browser games, developer tools, and creative experiments.

Designed as a central home for my work, NexusHub allows visitors to explore projects, discover new ideas, view screenshots, try live demos, and share feedback.

### ✨ Key Features

- **Interactive Project Showcase** — Browse projects with detailed descriptions, screenshots, and live links.
- **Categories & Search** — Easily discover projects by category or keyword.
- **Google Authentication** — Secure sign-in powered by Firebase Authentication.
- **Ratings & Reviews** — Visitors can share feedback on published projects.
- **Owner Dashboard** — A protected admin interface for creating, editing, and publishing projects.
- **Responsive Design** — A clean, minimal interface optimized for desktop and mobile.
- **Cloud Database** — Firebase Firestore manages project information and user feedback.
- **Static Image Hosting** — Project images are served through GitHub and Vercel.

### 🛠️ Tech Stack

HTML5 • CSS3 • JavaScript • Firebase Authentication • Cloud Firestore • GitHub • Vercel

### 💡 Why I Built NexusHub

As a student developer, I wanted one place where I could organize my projects, document my progress, and share what I'm building with others.

NexusHub is both my personal portfolio and a continuously evolving showcase of my journey in software development.
